# enciclopedia-super-herois

✨ Sobre o projeto

O projeto tem como objetivo criar uma página simples, organizada e visualmente agradável, apresentando informações sobre diferentes heroínas em um único site.

A proposta utiliza um visual inspirado no universo dos super-heróis, com elementos delicados e modernos.

Funcionalidades

- Apresentação de 3 heroínas
- Cards com imagens e informações
- Navegação dentro da própria página
- Layout organizado e responsivo
- Efeitos visuais utilizando CSS
- Página desenvolvida sem JavaScript

Tecnologias utilizadas

- HTML5
- CSS3

Projeto acadêmico

Projeto desenvolvido como atividade acadêmica para aplicação dos conhecimentos de HTML e CSS.
